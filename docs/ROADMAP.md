## 下一阶段的优先级

1. **新的独立评估数据**：跨城市/设备、多日期、更多完整路线；先约定留出和分母，保留失败与参考缺失。更多相关历元不能替代更多独立采集。
2. **同源NLOS到定位闭环**：在匹配的原始观测中用逐卫星预测做加权或受几何约束剔除，对比SPP/稳健方法，报告漏检、误剔除、几何损失和可用率。
3. **更完整的定位方法**：按可用输入研究Doppler/TDCP因子图、周跳与弧段管理。完整GNSS/IMU另需同步、姿态、重力/偏置和杆臂，当前平面接口尚未完成这些处理。
4. **独立RAG质量检查**：增加未参与修订的新用户问题，分别检查检索、数值、引用支持、过度归因、可读性、延迟与输入预算；再考虑重排器或多次生成稳定性。
5. **参考标签质量**：动态车辆/树木和遮挡物类别需要真实标注；审计静态建筑/相机参考的不确定性与被排除样本。
