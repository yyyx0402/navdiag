# 实现状态与扩展路线

v0.2 是一个完整可运行的公开数据作品版本。你可以先运行和阅读，再决定是否扩展为更强的研究实验。

## 已实现

- Python 包、CLI、本地 `.venv`、VS Code 调试配置、测试与 CI。
- GSDC 2021/2022/2023 派生文件字段适配，固定版本下载与 SHA-256。
- GPS/UTC 时间、坐标转换、参考插值、等权 / 加权 / 稳健定位。
- 训练集缺失处理、整段采集分组、显式划分、规则 / LR / RF / 因果 GRU。
- 验证集模型/阈值选择、无参考标签的推理、持久化与结果报告。
- 固定 / 风险自适应平面滤波，验证集选参，模拟 ENU 加速度接口。
- 六种只读工具、八篇原创技术笔记、GPT Responses / DeepSeek 工具调用。
- 30 个固定诊断问题、离线工具与引用检查、本地实验网页。
- 真实小样本与模拟实验记录、失败结果、模型卡与后续学习资料。

## 需要外部条件才能验证

- GitHub 已创建并推送公开仓库；后续每次改动仍需查看远程 CI。
- 实际 GPT / DeepSeek 回答质量：需要用户在本地配置 API 密钥。
- 更有代表性的真实成绩：需要更多完整独立行程；当前公开测试样例只有 11 个历元。

## 建议后续扩展

1. 获取完整 GSDC 数据，冻结多个完整测试行程，做设备/路线独立测试和按行程置信区间。
2. 分析严重错误、缺测和稳健 WLS 的回退场景；比较多频观测选择和权重模型。
3. 以可靠 IMU 数据实现时间同步、姿态、标定和惯导基线，再研究质量驱动融合。
4. 在独立验证分组做风险校准、滤波消融和偏差分析，保留没有提升的场景。
5. 用真实 API 比较直接问答、检索问答和工具 Agent，增加人工数字/推断正确性评分、成本和延迟。

这些是扩展实验，不属于当前公开版本已完成的能力或已验证成绩。简历描述只采用自己能够解释、实际运行且有记录的内容。
