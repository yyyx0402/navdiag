# 本地 v0.3：真实卫星遮挡识别

2026-10-11：本页是初期历史实验。当前已移除两项特征 RF 消融，新增完整 Transformer 分类器；当前设置和结果以 [Transformer 实验](transformer_nlos.md) 为准。KLT 结果不受 GSDC 时间修正影响，v0.2 真实定位结果则已[撤回并重算](gsdc2021_correction.md)。

2026-10-10，本次改动仅在本地，未上传 GitHub。原 v0.2 的定位失准/融合结果保留，新增任务不与其 F1 直接比较。

## 任务与来源

对每颗已跟踪卫星在每个时间点预测 LOS/NLOS。采用 [Fossett Laboratory 已发布特征表](https://github.com/fossettlab/gnss-nlos-notebook)，其相机参考标签来自 [KLT 原始数据集](https://github.com/ebhrz/KLTDataset)。不把定位误差阈值或模型规则当作遮挡真值。没有高楼/树木物体类型，也没有完全丢失信号标签。

来源 commit 为 b13aa856f723a472bd35d45171017580642054cf，压缩表 SHA-256 为 4955326b4e25ffd9be6f86bc3111c2fecd6e5db1aa33e975d15b83aa4304434f。原表与 GPL-3.0 许可保存本地、不随原创 MIT 代码打包。

## 冻结设置

| 划分 | 区域 / 采集段 | 定位历元 | 卫星观测 | NLOS 比例 |
| --- | --- | ---: | ---: | ---: |
| 训练 | KLT2 / 1109_KLT2_294、1109_KLT2_301 | 595 | 9,830 | 34.82% |
| 验证 | KLT1 / 1109_KLT1_421 | 421 | 6,607 | 36.48% |
| 测试 | KLT3 / 1109_KLT3_666 | 666 | 10,085 | 35.74% |

同一区域的采集段不跨集合。种子 42，训练集 median 填充；特征是单星 C/N0、仰角、归一化 SPP 残差、伪距/Doppler 变化率一致性、历史 C/N0 标准差。LR 使用标准化和 balanced 类别权重；RF 为 200 棵树、深度 12、最小叶节点 8、balanced 权重。两项特征 RF 仅使用 C/N0 和仰角，其余设置相同。

模型和分类阈值只按验证 F1 选择，阈值网格 0.05–0.95，间隔 0.05；固定规则为 C/N0 < 30 dB-Hz。测试不选模型或阈值。

## 结果

| 方法 | Val F1 | Test Precision | Test Recall | Test F1 | Test 误报 / 漏报 |
| --- | ---: | ---: | ---: | ---: | ---: |
| C/N0 固定规则 | 0.651 | 0.621 | 0.625 | 0.623 | 1,377 / 1,352 |
| LR 五特征 | 0.746 | 0.796 | 0.658 | 0.720 | 609 / 1,232 |
| RF 五特征（验证选中） | 0.757 | 0.672 | 0.778 | 0.721 | 1,366 / 801 |
| RF C/N0 + 仰角 | 0.717 | 0.573 | 0.759 | 0.653 | 2,041 / 867 |

全部判 NLOS 的测试 F1 为 0.527；全部判 LOS 的 F1 为 0，Accuracy 仍有 0.643。故只看准确率或召回率容易误判效果。模型选择仍以验证集为准。

RF 找到 3,604 条 NLOS 中的 2,803 条，误报 1,366 条 LOS、漏报 801 条 NLOS。它优于简单规则，但误报、漏报仍明显；还不是完成项目的最终成绩。

强信号 NLOS 漏检突出，弱信号 LOS 也会误报。GPS 测试 F1 为 0.768，BeiDou 为 0.675；这只是该段的分组结果，不能归因于星座本身。区域、几何、信号分布及标签质量仍可能混杂。

原模拟定位失准模型则是另一项任务：测试 360 个历元，TP 84、FP 81、FN 3、TN 192。高 Recall 0.966 与 Precision 0.509 同时存在，源于误报多。固定滤波优于自适应滤波的失败结果继续保留，尚未证明学习模块改善导航。

## 可复现与边界

```powershell
.\.venv\Scripts\python.exe scripts/fetch_nlos_data.py
.\.venv\Scripts\python.exe -m navdiag prepare-klt
.\.venv\Scripts\python.exe -m navdiag train-nlos
.\.venv\Scripts\python.exe -m navdiag serve --artifacts artifacts/navigation_demo --nlos-artifacts artifacts/klt_nlos
```

原始相机标签和特征提取过程未重新验证；这里只有四段、同一天、同一设备、三个相邻区域。卫星观测有时间/同历元相关性，不能按 10,085 个独立试验计算置信区间。这里也没有同源卫星坐标/伪距完整定位输入，因此不声称“排除 NLOS 后位置精度提高”。

完整数值报告保存在本地 artifacts/klt_nlos/report.json。后续增加原始多日期采集及可靠场景标签，在新留出集评估，再研究同一观测下 NLOS 降权与定位效果。当前已查看的测试切片不用于反复调参。

数据质量修正：网页复核发现 927 条 C/N0=0，占位记录按缺测处理，重算五个历史/当前观测的 C/N0 波动；其他参数与区域划分未调整。上表为修正后的最终本地记录，第一轮未清洗数值已被替换。缺测测试记录单列统计，不被算入弱信号分组。
