# UrbanNav 未见城区识别

公开 F9P splitter、SPAN 参考与建筑图用于尖沙咀TST、黄埔WP、旺角MK。全部在香港，各区仅一次采集，不能代表跨城市泛化。标签为 `static_3d_sky_mask` 几何参考，非人工逐星接收真值。

## 数据与标签覆盖

| 城区 | 日期 | 原始观测历元 | 可评分历元 | 卫星观测 | 可评分观测 | unknown | 标签覆盖率 |
|---|---|---:|---:|---:|---:|---:|---:|
| 尖沙咀 TST | 2021-05-17 | 786 | 637 | 10,385 | 6,087 | 4,298 | 58.6% |
| 黄埔 WP | 2021-05-21 | 1,535 | 1,284 | 20,951 | 12,494 | 8,457 | 59.6% |
| 旺角 MK | 2021-05-18 | 3,350 | 1,030 | 46,408 | 9,258 | 37,150 | 19.9% |
| 合计 | 三次采集 | 5,671 | 2,951 | 77,744 | 27,839 | 49,905 | 35.8% |

独立位置/星历计算可见性；时间差≤50ms、Q≤2、最近网格≤2m、3m内最多四网格、高度差≤3m、边界间隔5°。边界、缺星历或参考覆盖不足保持unknown；原始0°/360°不一致值共同进入包络。保护参数固定于评分前，未经人工真值校准。

模型仍用同源五项无线电/SPP特征，参考位置/建筑图/标签不作输入。unknown不参与评分，未跟踪卫星无标签；静态图不能覆盖树木或车辆，LOS可含多径。新记录距KLT最近约2666/2196/996m，没有路线重合，但仍同城。

## 协议

冻结外部迁移使用 KLT `cross_region_klt3` 全部源模型和源验证阈值；UrbanNav不参与选模，源验证选中LSTM。城区互斥以一个完整城区训练、另一区验证、第三个测试，交换源角色形成六方向。默认固定参数、种子42、最多30轮，阈值和检查点只使用该折验证区。

六方向复用三条路线，不是六个独立地区。先平均同城区两方向，再等权平均三城区；汇总验证赢家不是额外部署模型。域差异同时包含设备、日期、参考方法、标签比例和筛选效应。

总体F1为RF领先，旺角Transformer更高；单城区优势不能推广。旺角仅19.9%卫星观测获准评分。泛化有效性取决于目标是否留出、标签与阈值是否独立，性能下降不是必要条件。[分布审计](nlos_domain_audit.md)另报告C/N0差异。

## 复现与来源

```powershell
python scripts/fetch_urbannav.py
python tools/urbannav/fetch_extractor.py
python tools/urbannav/prepare.py
python -m navdiag evaluate-nlos-regions
```

先准备KLT源模型和[可选依赖](../README.md)。固定输入见[源清单](../../config/urbannav_sources.json)，配置见[计划](../../config/nlos_generalization.json)，当前汇总见[JSON](urbannav_generalization_report.json)。冻结目录拒绝覆盖。

来源：[UrbanNav](https://github.com/IPNL-POLYU/UrbanNavDataset)，Hsu等2023，DOI10.33012/navi.602；[NOAA](https://ngs.noaa.gov/CORS/data.shtml)、[SatRef](https://www.geodetic.gov.hk/en/rinex/downv.aspx)当天星历。UrbanNav缺少明确数据再分发许可，SatRef限个人非商业内部使用；原始/派生表与权重不发布。独立GPL适配器见[工具说明](../../tools/urbannav/README.md)。
