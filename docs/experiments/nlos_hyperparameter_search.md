# NLOS 超参数搜索（2026-10-11）

上一轮五网络比较采用统一默认设置，不代表各类网络的性能上限。用户要求寻找相对更好的超参数并检查能否超过 baseline。本轮预先冻结候选，仅在验证集选择，再评估已查看过的开发阶段留出区域。没有根据测试结果追加候选、强制神经网络获胜或重新选择模型。

## 协议与预算

使用相同 KLT 表、种子 42、区域划分和五项特征。LR、RF、MLP、CNN、LSTM、GRU、Transformer 各 8 组，共 56 组；每族包含原默认配置。计划见 [nlos_search.json](../../config/nlos_search.json)。模型仍从训练集学习参数与预处理，候选排名和分类阈值来自验证 F1。

神经网络候选覆盖历史长度 1/8/16/32、宽度 32/64/128、层数 1/2、学习率 0.0002/0.0005/0.001、dropout 0.1/0.2/0.3、weight decay 0.001/0.01/0.05；CNN kernel 3/5，Transformer heads 2/4/8。这是八组有意义的联合配置，不是所有取值的笛卡尔积，也不是全局最优搜索。候选中可能有不适用于某架构的通用配置字段，实际结构另存于 architecture_settings；单层 RNN 没有层间 dropout。

神经网络固定 AdamW、类别加权 BCE、batch 128、最大 30 轮、验证 BCE patience 6，恢复最低验证损失参数。之后在验证集上搜索 0.05–0.95、步长 0.05 的分类阈值。RF 搜索深度、叶大小、max_features、类别权重与树数；LR 搜索 C 与类别权重。所有历史窗口仍是同一卫星过去/当前，跨设备/行程/卫星/大间隙重置。

每个试验只生成验证指标与训练记录。`search_trace.json` 不记录试验测试分数；全部候选结束后先保存 `selection_before_test.json`，再以选定参数重训和评估。重训验证 F1/阈值与冻结选择严格核对。当前只有一个验证区域，尚未进行多区域嵌套交叉验证，搜索会增加对这个区域过拟合的可能。

## 默认与验证优选配置对比

| 模型 | 默认 Val F1 | 调参 Val F1 | 默认 Test F1 | 调参 Test F1 |
| --- | ---: | ---: | ---: | ---: |
| LR | 0.7459 | 0.7462 | 0.7204 | 0.7202 |
| RF | 0.7565 | 0.7576 | 0.7212 | 0.7164 |
| MLP | 0.7328 | 0.7541 | 0.7052 | 0.7150 |
| CNN（验证选中） | 0.7491 | 0.7637 | 0.7190 | 0.7215 |
| LSTM | 0.7436 | 0.7541 | 0.7077 | 0.7243 |
| GRU | 0.7509 | 0.7531 | 0.7105 | 0.7154 |
| Transformer | 0.7453 | 0.7489 | 0.7118 | 0.7178 |

每种模型的默认配置都进入搜索，因此验证 F1 不下降是选择机制的结果，不是额外独立泛化证据。RF/LR 的测试分数下降，说明验证改善不保证测试改善。

CNN 的验证 F1 最高（0.7637），本轮全体与神经网络组均选 CNN；LSTM 的测试 F1 最高但不因此改选。CNN Test F1=0.7214756，原 RF=0.7212145，差约 0.000261（0.0261 个百分点），不足以认定稳定提升。只有一个种子和一个测试区域，没有独立行程重复实验或统计显著性证据。

| 方法 | Test Precision | Test Recall | 误报 | 漏报 |
| --- | ---: | ---: | ---: | ---: |
| 原 RF baseline | 0.6723 | 0.7777 | 1,366 | 801 |
| 本轮 CNN | 0.6869 | 0.7597 | 1,248 | 866 |
| 本轮 RF | 0.6470 | 0.8024 | 1,578 | 712 |
| 本轮 LSTM | 0.7222 | 0.7264 | 1,007 | 986 |

CNN 相对原 RF 少了 118 次误报，但多了 65 次漏报。F1 微增不等于每项指标都改善，也不等于定位更好。这里仍按照用户希望的 Precision 与 NLOS 检出率折中选模，没有 90% Recall 硬约束。

## 选出的设置

| 模型 | 验证优选的主要参数 | 分类阈值 |
| --- | --- | ---: |
| LR | C=10，balanced | 0.60 |
| RF | 200 树，depth=None，leaf=2，sqrt 特征，balanced | 0.40 |
| MLP | window=16，hidden=128/64，dropout=0.3，lr=0.0005，wd=0.05 | 0.60 |
| CNN | window=16，64 通道×2，kernel=5，dropout=0.3，lr=0.0005，wd=0.05 | 0.45 |
| LSTM | window=16，hidden=32，1 层，lr=0.001，wd=0.01；无层间 dropout | 0.50 |
| GRU | window=16，hidden=32，1 层，lr=0.001，wd=0.01；无层间 dropout | 0.55 |
| Transformer | window=16，width=64，2 层，4 头，dropout=0.3，lr=0.0005，wd=0.05 | 0.55 |

CNN 最佳轮为 20，实际运行 26 轮。多项参数同时改变，不能把增益归因于某一个设置；本轮没有做用户未要求的组件消融。

## 运行和产物

```powershell
.\.venv\Scripts\python.exe -m navdiag tune-nlos
.\.venv\Scripts\python.exe -m navdiag serve --artifacts artifacts/navigation_demo --nlos-artifacts artifacts/klt_nlos_tuned
```

默认配置产物保留于 `artifacts/klt_nlos`，调参产物位于 `artifacts/klt_nlos_tuned`。后者包含 plan、完整 trace、测试前选择快照、原 baseline 报告、最终 report/predictions/models。可发布的指标快照是[搜索报告](nlos_hyperparameter_search_report.json)，原始数据和模型不发布。所有改动仅本地，未上传 GitHub。

代码位于 `nlos_search.py`，结构与训练的参数接口位于 `nlos_neural.py`。测试通过改变全部测试标签与特征，检查选中的超参、验证阈值、模型和权重不改变；同时核对测试评估发生前已有冻结选择记录，并验证五种非默认网络配置可运行。

这一轮说明默认设置的比较确实不充分，也说明调参不能保证突破现有数据限制。进一步提升需要更多独立日期/区域、同源缺失特征和新最终留出集。不得把开发区域上约 0.0003 的 F1 差距写成稳定性能提升。
