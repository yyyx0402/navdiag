# 同域与跨区域 NLOS 实验

目的：比较相同测试采集段上，不同模型在“训练见过该区域的其他采集段”和“训练完全没见过该区域”两种条件下的表现。暂停超参数搜索，使用原始固定默认配置；分类阈值和早停检查点仍只由验证集决定。

六个固定参数实验已完成。完整训练与逐卫星预测保存在本地 `artifacts/klt_protocols`，可公开的结果摘要见 [结果 JSON](nlos_protocols_report.json)。

## 数据与预处理

[原始 KLT 数据](https://github.com/ebhrz/KLTDataset)公开十段、三个日期的采集。作者明确标注 `1116_KLT3_649` 的标签不可靠，该段排除。其余九段官方清单合计 2,851 个历元、45,228 条 GPS/BeiDou 卫星观测；比此前四段的 1,682 / 26,522 增加约 70%。实际导入数量和逐段对齐检查保存在预处理报告中。

所有九段用同一个固定版本的 [Fossett Laboratory 特征提取器](https://github.com/fossettlab/gnss-nlos-notebook/blob/b13aa856f723a472bd35d45171017580642054cf/extract_features.py)重新计算，避免新增段和旧段使用不同的残差定义。通过 RTKLIB SPP 得到仰角、归一化伪距残差，结合 C/N0、伪距变化与多普勒一致性及过去五次观测的 C/N0 标准差。C/N0 非正值视为缺失，超过五秒的间隔重置历史；缺失值填补和标准化只拟合训练集。SPP 不使用相机标签排除卫星，也不使用定位真值计算特征。

四段旧数据的标签使用固定版本公开数值表，五段新增数据使用原始鱼眼相机标注。每一条标签按实际时间戳与卫星 ID 核对。原始配置的结束时刻会包含多一个观测历元，因此以标签的真实首尾时刻为提取窗口，并要求窗口长度和标签完全一致，不能靠截断较长数组“对齐”。外部 GPL 提取器和这个项目的独立 GPL 预处理工具见 [工具说明](../../tools/klt/README.md)；它们不打包到 MIT 主 Python 包中。

## 两种实验与比例

标签计数核对：`0610_KLT3_404` 的原始文件实际含 2,461 条 NLOS、3,848 条 LOS，与原作者 README 表中的 2,391 / 3,918 相差 70 条。本项目保留原始文件标签并记录其 SHA-256，未为了吻合摘要计数而改变标签；相机标签准确度仍未独立人工复核。其他八段的计数与原始清单一致。

每种实验分别评估 KLT1、KLT2、KLT3，共三对、六次固定参数实验。区域是九龙塘内部的三个区域，不是三个城市。

| 目标测试区域 | 共同测试采集段 | 共同验证采集段 |
|---|---|---|
| KLT1 | `1109_KLT1_421` | `0610_KLT3_404`, `1116_KLT2_169` |
| KLT2 | `1109_KLT2_301`, `1116_KLT2_169` | `0610_KLT3_404`, `1116_KLT1_184` |
| KLT3 | `1109_KLT3_666` | `0610_KLT1_203`, `1109_KLT2_301` |

同域训练覆盖三处区域，包含测试区域的其他完整采集段；跨区域训练和验证仅覆盖另外两处区域，目标区域的非测试采集段也全部排除。每对实验的验证段、测试段、网络参数、种子和训练规则相同。移除目标区域训练段后，跨区域训练样本也减少，因此差值包含区域经验与训练量的共同影响，不能解释为单一因素的因果效应。

| 目标区域 | 同域 train/val/test 历元 | 同域比例 | 跨区域 train/val/test 历元 | 跨区域比例 |
|---|---|---|---|---|
| KLT1 | 1,857 / 573 / 421 | 65.1 / 20.1 / 14.8% | 1,470 / 573 / 421 | 59.7 / 23.3 / 17.1% |
| KLT2 | 1,793 / 588 / 470 | 62.9 / 20.6 / 16.5% | 1,290 / 588 / 470 | 54.9 / 25.0 / 20.0% |
| KLT3 | 1,681 / 504 / 666 | 59.0 / 17.7 / 23.4% | 1,277 / 504 / 666 | 52.2 / 20.6 / 27.2% |

6∶2∶2 是目标，实际比例按完整采集段略有偏差。不能拆相邻历元或随机打散同一历元的卫星来凑比例。以上按历元统计，卫星观测行比例另行报告。两种实验均是跨采集段划分，不是严格的时间预测或整日期留出；部分同日 KLT2 采集段相邻，这可能使同域任务更容易。

## 模型与比较方法

MLP、1D CNN、LSTM、GRU、Transformer 均使用同一卫星过去及当前的 32 次观测，网络宽度 64、两层、dropout 0.1，AdamW 学习率 0.0005、weight decay 0.01、batch 128；最多训练 30 轮，验证 BCE 早停 patience 6。Transformer 四头；CNN 卷积核 5。完整参数来自 [固定计划](../../config/nlos_protocols.json)和运行前冻结的 `experiment_plan.json`。

LR、RF 和 C/N0 规则使用当前观测特征。RF 固定为 200 棵树、最大深度 12、叶子至少 8 个样本、类别均衡；LR 固定 C=1、类别均衡。这是完整分类器对比，神经网络与树模型的历史输入不同。此前 56 组搜索的获胜参数没有迁移到这次主实验，也没有继续搜索。

分别报告每个目标区域的 Test Precision、NLOS Recall、F1、误报、漏报和验证集确定的阈值，再计算三个区域等权平均。平均 F1 是逐区域 F1 的平均，不是先平均 Precision/Recall 再算其调和平均。网页可切换六个具体实验，查看每次划分、全部模型、逐卫星预测和错误切片。

测试排名用于描述这次观察结果。每折选模使用验证 F1，两种协议的汇总选模使用平均验证 F1；不能再按最高测试分选择部署模型。仅一次种子、三个相邻区域，微小差异不能证明稳定优势。2023-11-09 的若干采集段在早期开发中已被查看，因此这是探索性比较，不能声称全新的最终盲测。相机标签质量、低光条件、日期变化、卫星几何和样本量都可能影响结果。

## 本次运行结果

六个固定参数实验已完成，使用原始默认配置；汇总见 [结果 JSON](nlos_protocols_report.json)。下表为三个目标区域的等权测试均值，**测试领先者用于描述结果，不用于重新选模**。

| 模型 | 同域 Precision | 同域 Recall | 同域 F1 | 跨区域 Precision | 跨区域 Recall | 跨区域 F1 | F1 变化 |
|---|---:|---:|---:|---:|---:|---:|---:|
| LR | 0.7089 | 0.7779 | 0.7388 | 0.7330 | 0.7681 | 0.7431 | +0.0043 |
| RF | 0.7725 | 0.7481 | 0.7558 | 0.7756 | 0.7320 | 0.7494 | -0.0064 |
| MLP | 0.7256 | 0.8051 | 0.7612 | 0.7278 | 0.7813 | 0.7533 | -0.0079 |
| CNN | 0.7083 | 0.8226 | 0.7560 | 0.7093 | 0.8119 | 0.7528 | -0.0032 |
| LSTM | 0.7317 | 0.7856 | 0.7554 | 0.7069 | 0.8112 | 0.7504 | -0.0051 |
| GRU | 0.7361 | 0.7896 | 0.7600 | 0.7107 | 0.8081 | 0.7542 | -0.0057 |
| Transformer | 0.7184 | 0.8069 | 0.7574 | 0.7200 | 0.7965 | 0.7557 | -0.0017 |
| C/N0 rule | 0.6355 | 0.6189 | 0.6270 | 0.6355 | 0.6189 | 0.6270 | +0.0000 |

![双协议模型比较](../images/nlos-protocol-comparison.png)

同域测试均值中 MLP F1 最高（0.7612），跨区域 Transformer 最高（0.7557）。两个协议中 RF 的平均 Precision 最高，CNN 的平均 NLOS Recall 最高。按平均验证 F1 选择的模型族分别为 GRU 和 Transformer；同域测试最高的 MLP 没有因测试成绩被重新选中。模型差距较小，尚不足以认定稳定优势。

跨区域没有出现全模型的大幅下降，LR 的平均 F1 甚至略升；KLT3 的多种模型也略升。这里三处区域相邻、接收机相同、输入是同源的信号与几何特征，移除目标区域训练段还改变了日期分布和训练量，验证早停与阈值也随训练模型改变。因此这个结果不能证明跨城市 NLOS 容易泛化，也不能将每个差值都解释为纯区域效应。

各区域的测试 F1 领先者如下（同样仅为观察排名）：

| 目标区域 | 同域 | 跨区域 |
|---|---|---|
| KLT1 | GRU 0.7728 | RF 0.7695 |
| KLT2 | RF 0.7759 | Transformer 0.7654 |
| KLT3 | Transformer 0.7483 | GRU 0.7538 |

两种协议的测试采集段逐条核对一致：KLT1 6,607 行、KLT2 7,551 行、KLT3 10,085 行；五项输入特征在全部六个实验中保留。每种神经网络上限 30 轮，实际运行 7～20 轮，由验证 BCE 早停。所有阈值来自验证集；数据和固定参数计划在运行前已冻结。
