# 泛化评估

完整采集段和区域留出分别回答不同问题。[UrbanNav 结果](../experiments/urbannav_generalization.md)与[分布审计](../experiments/nlos_domain_audit.md)提供当前证据。

## 相同测试段上的固定规则为何不变

固定规则 `score = (C/N0 < 30)` 不读取训练数据。输入测试观测与参考标签不变，Precision/Recall/F1 就不会变化。因此它能作为简单参照，却不能通过“同域列－跨区域列”判断训练域偏移。训练过的 RF/神经网络会随训练集合变化；不同测试区域的规则成绩也可以不同。

## 先明确自己要回答的问题

- 完整采集段留出、区域在训练中出现：学习已见环境能否延续到另一段记录。
- 完整城区留出：学习过的特征关系能否适用于未见城区。
- 完整城市留出：在新的建筑环境、设备/天线/卫星条件下能否迁移，且哪些变化可以与城市因素分开。

难度不能只由“同城”或“异城”的名字判断；实际条件分布、采集独立性和标签质量更关键。成绩相近不等于实验无效，成绩下降也不能自动证明纯地理影响。

## C/N0 并不只由城市决定

应区分全体分布与 LOS/NLOS 条件分布，检查星座、频率、仰角、天线安装、接收机配置、日期和类别比例。旧 KLT 三处总体曲线接近；UrbanNav 同城三处仍有差异。标签筛选也会改变条件分布，旺角未获准评分的样本占比很高。

不能用目标测试数据的标签调归一化、模型参数或阈值，再称为完全未见域测试。若计划研究无标签域适应，应单独声明适应数据和不参与适应的最终测试；它是另一个研究问题。
