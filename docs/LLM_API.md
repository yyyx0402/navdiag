# 模型与 API

在网页“诊断助手 → 自定义模型 API → 配置模型与 API”填写连接名称、基础地址、模型 ID 与密钥，点击“保存并使用”。支持多个连接；保存配置不调用模型，提交问题才生成回答。

## 接口

使用 Chat Completions 兼容格式，请求 `基础地址/chat/completions`。完整聊天地址会规范化为基础地址。模型 ID、账户额度与工具能力由所选服务决定。

| 服务 | 地址示例 | 模型 |
| --- | --- | --- |
| 远程供应商 | 服务商提供的 HTTPS 基础地址 | 账户实际可用 ID |
| Ollama | `http://127.0.0.1:11434/v1` | 本地已安装模型 |
| vLLM | `http://127.0.0.1:8000/v1` | 部署时发布的模型名 |

“获取模型列表”只请求 `/models`，不进行推理；服务不支持列表时可手填 ID。列表成功不能证明推理额度或工具调用正常。本地服务需自行启动，参考 [Ollama 兼容接口](https://docs.ollama.com/api/openai-compatibility)。

## 回答方式

| 方式 | 行为 |
| --- | --- |
| 离线速查 | 本地工具与模板，无模型请求 |
| 证据问答 | 本地检索/读取指标后进行一次聊天请求，无依据则本地提示 |
| 工具 Agent | 模型选择限定只读工具，最多五轮，每轮最多六个调用；需支持 function calling |

输出上限128–32768 tokens、请求超时5–300秒、可选推理强度；新连接默认4096 tokens。只选择服务支持的参数。引用检查验证编号存在，不认证结论；截断答案会显示不完整标记。

## 配置保存

连接保存于 `.navdiag/llm_connections.json`，密钥以明文存储在本机，读取接口只返回是否已保存。该目录已 Git 忽略并受发布检查保护。指定 `--env-file` 时，连接目录位于该文件同级。

编辑连接时密钥留空表示保留，勾选清除表示移除；更换地址必须重新填写对应密钥或明确清除。请求不跟随重定向。远程地址使用 HTTPS，本地回环允许 HTTP。问题及相关证据发送到所选服务，付费按服务规则处理。

命令行可使用 `.env.example` 的 `compatible` 配置，或通过 `ask --connection 连接ID` 复用网页连接；`--connection` 与 `--provider` 二选一。`NAVDIAG_ANSWER_MODE=evidence/tools` 选择回答方式。

## 常见错误

| 提示 | 检查项 |
| --- | --- |
| DNS/TLS/拒绝连接 | 地址、代理、证书和服务是否运行 |
| HTTP401/403 | 密钥、账户权限与模型授权 |
| HTTP429 | 额度、并发/频率限制与套餐接口是否匹配 |
| 超时 | 网络、服务负载、输出预算和推理设置 |
| 空回答/预算耗尽 | 模型 ID、输出上限、推理模式与内容过滤 |

错误不回显供应商原始敏感文本，不自动发起付费重试。已有 [GLM-5.3 小型真实回答检查](experiments/glm_quality.md)，不代表所有模型或配置都已验证。
