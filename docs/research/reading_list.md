# RAG 文献摘要与阅读清单

当前 API 模型只通过 NavDiag 的七个本地证据工具读取资料，不自动访问网络。搜索和核对由开发阶段完成，再将有来源的短篇研究摘要纳入知识库。日后若加入联网搜索，仍需实现搜索工具、原始来源核对、网页内容过滤和引用记录；模型能理解问题不等于接口已经具备联网能力。

本轮按 Academic Research Suite 的轻量论文比较与来源核对流程，在同一会话中完成；没有独立多代理或跨模型审查，不是系统综述。范围为 GNSS NLOS 输入与预处理、跨场景边界和表格模型比较。核对日期为 2026-10-11。文献年代主要为 2021–2023，提供方法背景，不是“最新研究全覆盖”。

GNSS 文献给出不同层次的路线：相关器波形、RINEX 可导出特征、多频物理归一化、时空联合任务。输入可用性、标签方法和场景变化必须先匹配，不能只更换网络名字。通用表格文献则提供相互补充的视角：树模型经常很强，良好的深度基线也有价值，数据性质和统一比较协议比“深度一定更好”更值得核对。这些是跨文献的项目建议，不是本项目新增实验结果。

用于检索的条目保存在 `src/navdiag/resources/literature.json`：每篇包含作者、年份、版本链接、DOI、摘要、关键词、核对日期与阅读范围。只保存项目原创短摘要，不复制整篇 PDF 或大段原文。未进行独立复现、系统检索覆盖统计或撤稿数据库审计，不把来源存在性核对扩展成全面可靠性认证。

回答必须同时区分“文献作者观察”“NavDiag 当前实验指标”“待验证的建议”。泛化能力不能用论文中的别城结果替代；通用表格研究不能直接证明我们的 RF/Transformer 排名。实际数值仍由 `compare_nlos` 等本地工具读取，模型不会自行补出未做的实验。
