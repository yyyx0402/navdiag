# 第八课：定位精度、可用率与Doppler对照

先看[完整路线报告](../experiments/positioning_expansion.md)，再阅读 [availability.py](../../src/navdiag/availability.py)、[context.py](../../src/navdiag/context.py)和 [doppler.py](../../src/navdiag/doppler.py)。当前真实评估包括三条整段路线；旧11点GSDC留出是历史解析样例。

## 三个分母

旺角原始历元3350个，有效单点解577个；时间与质量合格参考1270个，其中139个同时有有效解、可以评分。

| 计算           | 含义                                 |
| -------------- | ------------------------------------ |
| 577/3350=17.2% | 全部原始历元中的SPP可用率            |
| 139/3350=4.15% | 全段可评分比例，同时受解算和参考限制 |
| 139/1270=10.9% | 质量合格参考人口中的SPP可用率        |

对139点算RMSE，得到的是条件误差，不代表每秒均有可靠输出。自适应KF中16点≤2 m：16/139约11.5%；以全部合格参考为分母，“有输出且≤2 m”为16/1270约1.26%。缺测不能填零误差，也不能凭可评分跨度把139点称连续36分钟定位。

## 参考质量不应删掉历史输入

`observations.csv`保留所有成功SPP点；`epochs.csv`选择具有合格参考的监督/评分点；`availability.csv`记录全部原始历元的状态。滤波和GRU先处理完整成功观测历史，再由 `context_indices` 对齐评分行。参考不会进入实时模型，却能用于离线验证选择设置。

主实验是尖沙咀训练、黄埔验证、旺角测试；另固定循环轮换，让每条路线分别测试一次。采集段数量只有三条，区域与日期共同变化；当前数据在前期研究中已查看，不能冒称全新盲测或跨城市。

## KF和Doppler分别提供什么

普通平面KF的状态包括东/北位置和速度；Q描述过程不确定性，R描述测量不确定性。风险自适应方案用验证误差建立五个风险箱的R，并强制单调。这是经验映射，风险分数不是逐卫星NLOS概率。

Doppler速度由RTKLIB原始Doppler观测解算而来，不是参考轨迹差分。提取器检查速度和 `qv` 协方差，再将它们旋转到ENU；Doppler KF额外更新速度，检查创新NIS并在长间隙重置。位置/速度相关性近似为零，协方差没有完成独立误差校准。

两种方案只给已有成功SPP点输出，不为断解点额外计入有效位置。完整FGO、TDCP、IMU标定尚未完成；方法出处见[来源说明](../research/positioning_methods.md)。

## 判断改善需要多个指标

旺角SPP/Doppler RMSE为15.481/14.610 m，但P95为28.046/33.151 m，中位误差也退步。平滑曲线、较小RMSE或单个优秀历元，都不能单独证明连续导航更可靠。尖沙咀的Doppler RMSE变差也保留在报告中。
