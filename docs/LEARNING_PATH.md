# 先使用项目，再系统学习

你已经会 Python，先把每段代码对应的数学问题和验证方法理解清楚。每次 30–60 分钟，完成一个小任务即可。成品不要求你现在跟着重写。

| 顺序 | 知识 | 阅读位置 | 亲手完成的任务 |
| --- | --- | --- | --- |
| 1 | 特征、标签、数据泄漏 | [第一课](lessons/01_features_labels_splits.md)、`data.py` | 标出所有禁止作为特征的字段，核对 split |
| 2 | ECEF / ENU、伪距、最小二乘 | [第二课](lessons/02_positioning.md)、`positioning.py` | 对一组仿真观测加 30 m 偏差，看位置与残差怎样改变 |
| 3 | 时间、数据缺失、参考标签 | `gsdc.py`、`data/README.md` | 检查一个真实历元，解释 C/N0 为什么为空 |
| 4 | 混淆矩阵、Precision / Recall / F1 | [第三课](lessons/03_models.md)、`learning.py` | 手算一次误报/漏报，说明 11 个全负样本为何不能算 Recall |
| 5 | Pipeline、标准化、过拟合 | `learning.py` | 改 RF 深度，用验证集比较，先不重看测试集 |
| 6 | GRU、历史窗口、训练/推理 | `temporal.py` | 画出三个历元的窗口，检查未来值不能改变过去预测 |
| 7 | Kalman 状态和 R、消融实验 | `fusion.py`、`MODEL_CARD.md` | 解释固定滤波为何在当前模拟中胜过自适应滤波 |
| 8 | 工具调用、检索、证据引用 | [第四课](lessons/04_agent.md)、`agent.py` | 跟踪一个问题的 request → tool → evidence → answer |
| 9 | 单元与集成测试、可复现报告 | `tests/`、`agent_eval.py` | 阅读一个因果测试，写出它能证明和不能证明的事情 |
| 10 | 面试表达、项目边界 | `docs/experiments/v0_2.md` | 用五分钟讲清问题、实现、划分、结果与失败点 |

建议在 `docs/notes/` 写自己的笔记：我理解的三个概念、改动与预期、验证结果、仍不理解的一段代码。参数练习观察验证集，不把当前最终测试反复用于调参。完整真实基准和实际 LLM 评测属于后续扩展，不应把未做的部分写成自己的成绩。

第一遍可以忽略网络请求和网页样式，先读 CLI 如何把数据、定位、学习和输出串起来。第二遍再学 GRU、滤波和工具调用，第三遍自己完成一个小消融实验。
